# 一席话 | Hear Them Out

> One question. Many voices.

“一席话”是一款围绕**热点与经典问题**，邀请**热点与经典人物**展开多角色对谈的 Web 产品。

它把公开资料、人物观点与编辑策划组合成一场可阅读、可收听、可分享的 AI 对谈。所有内容都会明确标注：

> 基于公开资料的 AI 演绎，非本人发言，不代表本人观点。

## 开发代号

`yixi-studio`

## 当前 Web 基线

- Next.js 16 App Router
- TypeScript
- React 19
- 前端优先的本地种子数据
- 无第三方 UI 依赖，先用可替换的 CSS 视觉系统

## 第一版目标

- 浏览热点问题与经典问题
- 浏览热点人物与经典人物
- 选择一个问题和两位人物，生成一场结构化对谈
- 阅读逐轮对话、查看来源与事实依据
- 生成可选音频，分享结果
- 通过内部内容工作台维护问题、人物、来源和节目

## 已搭建页面

- `/` 首页
- `/topics` 问题库
- `/topics/[slug]` 问题详情
- `/people` 人物库
- `/people/[slug]` 人物详情
- `/create` 开一席
- `/episodes/[id]` 对谈结果
- `/studio` 内容工作台占位页

## 内容组合

1. 热点问题 × 热点人物
2. 热点问题 × 经典人物
3. 经典问题 × 热点人物
4. 经典问题 × 经典人物

## 本地运行

```bash
npm install
npm run dev
```

生产检查：

```bash
npm run build
npm run lint
```

- `app/`：App Router 页面
