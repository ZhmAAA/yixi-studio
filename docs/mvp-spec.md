# MVP 功能与页面规格

## 产品定位

一席话先做“内容策划驱动的 AI 对谈”，不做空白聊天框。用户从问题库和人物库中选择已有内容，再生成一场有来源、有结构、有明确演绎边界的对谈。

## P0 核心链路

1. 首页发现
   - 今日热点
   - 经典再聊
   - 精选一席
   - 开一席
2. 问题库
   - 热点问题 / 经典问题
   - 问题详情：背景、讨论角度、推荐人物、来源
3. 人物库
   - 热点人物 / 经典人物
   - 人物详情：身份、时代、观点摘要、适合讨论的问题、来源
4. 开一席
   - 选择一个问题
   - 选择两位人物
   - 选择对谈模式：访谈 / 对话 / 观点交锋
   - 选择时长：3–5 分钟
5. 生成与结果
   - 生成进度、失败重试
   - 逐轮对话稿
   - 事实与来源标记
   - AI 演绎声明
   - 可选通用 TTS 音频
   - 分享 / 再生成

## 页面结构

- `/` 首页
- `/topics` 问题库
- `/topics/[slug]` 问题详情
- `/people` 人物库
- `/people/[slug]` 人物详情
- `/create` 开一席
- `/episodes/[id]` 对谈结果
- `/studio` 内容工作台（内部）
- `/studio/topics`、`/studio/people`、`/studio/sources`、`/studio/episodes`

## 开发优先级

### P0：跑通一条可展示链路

- 内容模型与种子数据
- 首页与浏览页
- 问题 / 人物详情页
- 选择问题与人物
- 结构化对谈生成
- 结果页、来源和演绎声明

### P1：提升内容生产与复用

- 内容工作台审核、发布、下线
- 搜索、收藏、历史
- 3 位及以上人物
- 热点候选导入和人工确认
- URL / PDF 来源导入

### P2：后续探索

- 视频和数字人
- 实时语音对谈
- 用户自定义人物
- 社区互动和付费能力

## MVP 验收标准

- 用户无需输入长提示词即可开始一次对谈
- 每期对谈都能追溯到问题、人物和来源快照
- 热点内容有明确的时间范围和失效策略
- 经典内容有出处、时代背景和定期复核记录
- 页面始终显示“基于公开资料的 AI 演绎，非本人发言，不代表本人观点”
